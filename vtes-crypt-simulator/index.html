V:TES Crypt Draw Simulator

Start with at least N, at most N, exactly N, no or any, optionally distinct (count unique vampires instead of copies), then where and filters. Filters: cap (= != < <= > >=), disc, name, title, clan (= !=, ~ contains, in (a, b)). title = any / none match titled / untitled vampires. Uppercase disciplines such as POT require superior; lowercase pot allows either level. Combine with and, or, not and parentheses, both inside a filter and between clauses, e.g. any where name = "Anson" or at least 2 distinct where cap <= 4. Quote values containing spaces or commas.
