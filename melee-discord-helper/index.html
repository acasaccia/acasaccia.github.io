⚙️ API settings

Your Melee.gg credentials never leave this browser except to be sent to this site's proxy, which forwards them to melee.gg without storing or logging them. They are kept in this tab only, unless you save them. Saved credentials are stored unencrypted in this browser: only save them on a device you trust.

How do I get a Client ID and Client Secret?

Melee.gg issues API credentials manually, and only to tournament organizers and their designated staff:

  • You own the organization: email contact@melee.gg asking for API access for your organization.
  • You are staff of someone else's organization: you need Coverage Staff clearance on the tournaments (or the whole organization) you want to use, and the organization owner must email contact@melee.gg to confirm that you can be given API access.

Once the request is approved, Melee.gg generates your Client ID and Client Secret: paste them below.

The API exposes players' personal data, and the organization is responsible for how it is used. Treat the Client Secret like a password and never share it.

More details: Melee.gg help — API use.
